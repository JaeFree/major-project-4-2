# 라즈베리파이4 실행용 — pip로 설치할 항목만 이 파일에 둔다.
# 파이 OS: Raspberry Pi OS Bookworm 64비트(aarch64, Python 3.11)로 확정 (2026-10-14).
#
# [1] apt 설치 (시스템 라이브러리와 묶인 패키지는 반드시 apt로)
#   sudo apt update
#   sudo apt install -y python3-picamera2 python3-venv libzbar0 python3-serial \
#                       mosquitto mosquitto-clients
#
# [2] venv: apt의 picamera2를 그대로 쓰기 위해 --system-site-packages로 만든다
#   python3 -m venv --system-site-packages ~/barcode/.venv
#   ~/barcode/.venv/bin/pip install -r requirements-pi.txt
#
# 참고
#   - Bookworm의 apt python3-opencv는 4.6이라 cv2.barcode가 없다 → pip의 opencv-python-headless 사용.
#     (apt 판을 쓰면 OpenCV 엔진이 꺼지고 ZBar만으로 동작한다)
#   - numpy<2: apt의 picamera2/simplejpeg가 numpy 1.x로 빌드돼 있어 numpy 2가 venv에 들어오면 깨진다.
#   - Bookworm의 apt python3-paho-mqtt는 1.6.1 → venv에서 2.x 사용. 코드는 1.x/2.x 모두 지원한다.
#   - Trixie로 정해지면 apt python3-opencv(4.10, cv2.barcode 포함)·python3-paho-mqtt(2.x)로
#     대부분 apt 설치가 가능해 이 파일이 크게 줄어든다.

opencv-python-headless==4.11.0.86
numpy>=1.24,<2
pyzbar==0.1.9
paho-mqtt>=2.1,<3
pyserial>=3.5,<4
