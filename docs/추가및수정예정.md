하드웨어가 없어 확인하지 못한 항목은 `docs/미검증.md`에 따로 있다 (여기서는 "할 일"만 다룬다).

## 2. 검토 후보 (진행 중 제안된 개선, 필요할 때 결정)

| 상태 | 내용 | 이유 | 관련 위치 |
|---|---|---|---|
| ⬜ | MQTT 5로 전환해 ACL 거부를 발행 측에서 감지 | MQTT 3.1.1은 ACL로 거부된 발행도 PUBACK을 보내 스캐너가 성공으로 기록함 (지금은 사용자 이름 ≠ scanner_id면 경고만) | `mqtt_compat.py`, `publisher.py` (paho 1.x는 PUBACK 사유 코드를 주지 않아 2.x 전용이 됨) |
| ⬜ | ACL을 스캐너별 `user` 블록으로 바꾸기 | `pattern` 규칙은 db-writer·monitor·uno-bridge에도 적용됨 (지금은 db-writer가 토픽·내용 scanner_id 불일치를 거부해 보완) | `mosquitto/pi/acl`, `setup_broker.sh` |
| ⬜ | 시리얼 속도를 57600bps로 낮추기 | CH340 보드에서 115200bps 통신 오류가 잦을 경우 | `pins.h` `SERIAL_BAUD` + `config/uno_bridge.ini` `baud` (둘 다 같이) |
| ⬜ | UNO가 기억하는 lost 스캐너 수 늘리기 (지금 4개) | 스캐너가 5대 이상이 되면 | `pins.h` `MAX_SCANNERS` (SRAM 여유 확인) |
| ⬜ | 긴 바코드 값 LCD 표시 방식 (지금: 15자 + `~`) | 16자를 넘는 위치·팔레트 코드를 많이 쓰면 | `uno_display.ino` `copyFit` (스크롤 또는 뒷부분 표시) |
| ⬜ | NTP 동기화 여부를 메시지에 표시 → 우선순위 보통: 핫스팟으로 인터넷 사용 가능 (2026-10-15 확인) | 파이에 RTC가 없어 부팅 직후(NTP 동기화 전) 스캔 시각이 틀릴 수 있음 (지금은 DB에 수신 시각을 함께 저장). 핫스팟이 켜져 있으면 부팅 후 곧 동기화되지만, 핫스팟 없이 부팅하면 시각이 틀어짐 → 운영 전 `timedatectl`의 `System clock synchronized: yes` 확인을 절차로 둘지, 동기화 여부를 메시지에 넣을지 결정 | `messages.py`, `store.py` |
| ⬜ | outbox를 새로 만들 때 seq가 1부터 다시 시작하는 문제 | 누락 구간 조회(`db_tool gaps`)가 부정확해질 수 있음 | `outbox.py`, `store.py gaps()` |
| ⬜ | `max_queued_messages`(100000) 초과 대비 | db-writer가 아주 오래 꺼져 있으면 브로커가 이후 메시지를 버림 | `mosquitto/pi/barcode.conf`, db-writer 감시(systemd 재시작으로 일부 대응) |
| ⬜ | 대시보드 이력 조회가 최근 50건만 돌려줌 | 결과를 모르는 건은 이력에서 찾아보고 다시 보내는데, 그 상품에 그보다 늦은 시각의 이력이 50건 넘게 쌓이면 못 찾아 두 번 보낼 수 있음. 지금은 한 건씩 순서대로 보내 거의 생기지 않음. 대시보드가 중복 방지(예: 요청 ID)를 지원하게 되면 그쪽으로 바꾸기 | `dashboard_forwarder.py` `find_transaction` |
| ✅ | 파이 로케일이 UTF-8이 아닐 때 대비 → **파이 로케일을 en_US.UTF-8로 바꿔 해결 (2026-10-15)**, 코드 쪽 대비는 하지 않음. (requirements 파일에 `# -*- coding: utf-8 -*-`, systemd 유닛에 `Environment=PYTHONUTF8=1`) | 2026-10-14 파이에서 `pip install -r requirements-pi.txt`가 한글 주석을 Latin-1로 읽어 실패 (Bookworm venv의 pip 23은 로케일 인코딩을 먼저 씀). 앱 로그도 한글이라 같은 로케일이면 서비스 로그가 깨지거나 기록 오류가 날 수 있음. 우선 파이 로케일을 UTF-8로 바꾸도록 안내함 | `requirements-pi.txt`, `requirements-dev.txt`, `deploy/systemd/*.service` |
