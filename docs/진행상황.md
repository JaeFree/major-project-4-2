- 브로커 계정 비밀번호는 `setup_broker.sh` 인자 순서대로 입력함: dock-01, db-writer, monitor (값은 사용자가 앎)
- 학교 PC: 웹캠은 본체 뒷면 포트에 꽂아야 인식됨(장치명 `HD 4MP WEBCAM`). 다른 PC에서 가져온 `.venv`가 동작하지 않아 Python 3.12로 다시 만듦(기존은 `.venv.old`), 단위 테스트 157 통과·24 건너뜀 (2026-10-16)

- 인터넷: 아이폰 핫스팟으로 사용 가능 (NTP 동기화 가능)

- UNO: 중간고사에는 사용 안 함
- 스캐너: **Windows PC(학교 컴퓨터)**에서 실행, USB 웹캠 **PCWE400(펭가웹캠 2K)**. 파이에는 scanner 서비스 설치 안 함
- 파이에서 실행할 서비스: db-writer (+ 4단계 forwarder)

## 4단계 계획: 대시보드 전송 (2026-10-16 승인)

- 결정(2026-10-16): 잘못 읽음 대책(`types`)은 **기말고사**에 코드 수정, PC 스캐너는 `mode = presence`로 변경함, 실제 대시보드 시험 바코드는 `Apple123`, `pants2`

대시보드: https://dashboard.oswdev.cloud/ , 팀원 저장소 https://github.com/ohdongE/ErpSystem — **대시보드는 최대한 수정하지 않는다.**

- API: `POST https://api.oswdev.cloud/api/scan`, JSON `{barcode, deviceId, timestamp}` (모두 필수), 인증 없음, 응답 `{ok, barcode, transactionId}`
- 서버는 스캔마다 재고 +1·IN 이력 1건 (출고 없음). 처음 보는 바코드는 상품 자동 생성. 바코드는 대시보드에서 CODE128로 생성
- 서버에 중복 방지 없음 → 우리 쪽에서: 보낸 기록 관리, 응답이 없을 때는 `GET /api/products/<바코드>/transactions`에서 같은 deviceId+timestamp가 있는지 확인 후 재전송
- 새 모듈 `dashboard_forwarder` (DB에서 미전송 스캔을 읽어 전송), `config/forwarder.ini` (API 주소, 보낼 형식 기본 CODE128, deviceId 기본 scanner_id), `/` 포함 바코드는 보내지 않고 기록, systemd `barcode-forwarder`
- timestamp는 UTC `...Z` 형식으로 보냄 (서버가 문자열로 정렬, 기존 데이터 형식 `2026-08-28T09:00:00Z`)
- 테스트: 가짜 서버로 PC에서 시험 → 마지막에 실제 대시보드에 1~2건 (테스트용 바코드는 팀원과 상의)

## 다음 시작 시 안내문 (그대로 보여줄 것)

---

중간고사 범위(파이 배치 + 4단계 대시보드 전송)는 모두 끝났습니다. PC 웹캠으로 스캔하면 파이 DB에 저장되고, 파이가 대시보드로 보내 재고가 1씩 오릅니다. 파이를 켜면 브로커·db-writer·forwarder가 자동으로 실행됩니다.

**시연은 이 PC가 아닌 다른 PC에서 할 예정** (2026-10-16 사용자). 실습 날 그 PC에 필요한 설치·명령을 같이 진행하기로 함 → 아래 "시연 PC 준비" 참고.

**시연할 때 순서**
1. 아이폰 핫스팟 켜기 → 파이 전원 켜기 (서비스는 자동 실행)
2. PC를 USB Wi-Fi 어댑터로 핫스팟에 연결, 웹캠은 본체 뒷면 포트
3. PC PowerShell:
```powershell
cd D:\Barcode_System\Barcode_System
.\.venv\Scripts\Activate.ps1
python -m barcode_system.scanner_app --config config/scanner.ini --show true
```
4. 바코드를 비췄다가 치우기 (3초 이상 치워야 다음 스캔으로 기록됨)

**파이 상태 확인** (한글 없음)
```bash
systemctl is-active mosquitto
systemctl is-active barcode-db-writer
systemctl is-active barcode-forwarder
cd ~/barcode && source .venv/bin/activate
python -m barcode_system.forwarder_app --config config/forwarder.ini --status
```

## 시연 PC 준비 (다른 PC에서 시연할 때, 실습 날 같이 진행)

새 PC에서 확인·설치할 것 (스캐너만 실행하면 됨. 파이는 그대로)
- Python 3.11 또는 3.12 (`py -0p`로 확인), Git (`git --version`)
- 코드: `git clone https://github.com/JaeFree/major-project-4-2.git` (공개 저장소)
- venv: `py -3.12 -m venv .venv` → `.venv\Scripts\python -m pip install -r requirements-dev.txt` (스캐너만이면 opencv-python·numpy<2·pyzbar·paho-mqtt로 줄일 수 있음)
- pyzbar는 VC++ 2013 런타임 필요 (없으면 `import pyzbar.pyzbar`에서 DLL 오류)
- **git에 없는 파일 2개 새로 만들기**: `config/scanner.ini` (예시 복사 후 `camera = usb`, `host = a2500.local`, `mode = presence`), `config/dock-01.pass` (dock-01 비밀번호, 브로커 등록 순서상 첫 번째)
- 네트워크: 아이폰 핫스팟 연결 (유선만 있으면 USB Wi-Fi 어댑터), `Test-NetConnection a2500.local -Port 1883`
- 웹캠: 카메라 앱으로 인식 확인 후 앱 닫기, `--index` 번호 확인
- 확인: `python -m pytest -q` (선택), 스캐너 실행 후 파이 `--status`로 전송 확인
